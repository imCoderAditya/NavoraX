🚀 Getting Started

Add navorax package to your Flutter project's pubspec.yaml and build scalable navigation bars in seconds.

// 1. Basic NavoraX Widget
NavoraX(
  currentIndex: _currentIndex,
  items: const [
    NavoraXItem(icon: Icons.home_outlined, label: 'Home'),
    NavoraXItem(icon: Icons.explore_outlined, label: 'Discover'),
    NavoraXItem(icon: Icons.shopping_bag_outlined, label: 'Cart', badge: NavoraXBadge(type: NavoraXBadgeType.count, count: 4)),
    NavoraXItem(icon: Icons.person_outline_rounded, label: 'Profile'),
  ],
  onChanged: (index) => setState(() => _currentIndex = index),
)

🎛️ Complete Parameter & API Reference

Below is the detailed specification of every parameter, constructor, and function in NavoraX.

Class / Component Parameter Name Type Default Value Description & Usage
NavoraX currentIndex int Required The zero-based index of the currently active navigation item.
NavoraX items List<NavoraXItem> Required List of item models rendering icons, labels, badges, and tap handlers.
NavoraX onChanged ValueChanged<int> Required Callback invoked when a tab item is tapped by the user.
NavoraX template NavoraXTemplateEnum? null Selects one of the 1000+ pre-defined template designs (e.g. glassMorph, floatingPill).
NavoraX config NavoraXConfig? null Custom configuration built via NavoraXNavBuilder or .copyWith().
NavoraX centerAction NavoraXCenterAction? null Notched center Floating Action Button (FAB) config with custom size & icon.
NavoraX useSafeArea bool true Automatically adds bottom safe area inset padding for iOS Home Indicators & Android Gesture Bars.
NavoraX adaptive bool false Enables mobile OS-aware layout scaling, OLED dark adaptation, and accessibility scaling.
NavoraX contextAware bool false Enables reactive navigation state changes from NavoraXController.
NavoraX performanceMode NavoraXPerformanceMode auto GPU optimization mode (auto, high, balanced, low) to disable blur on low-end phones.
NavoraXConfig shape NavoraXShape flat Navigation bar geometry (flat, rounded, floating, pill, curved, wave, notched, liquid, dock).
NavoraXConfig indicator NavoraXIndicator lineTop Active item selection indicator (lineTop, lineBottom, dot, pill, ring, glow, stretchy, liquidBubble).
NavoraXConfig animation NavoraXAnimation fade Transition animation curve & style (fade, slide, scale, bounce, elastic, spring, morph, magnetic).
NavoraXConfig backgroundStyle NavoraXBackgroundStyle solid Background style (solid, glass, glassMorph, neumorphicFlat, neumorphicConvex, gradient).
NavoraXConfig height double 64.0 Height of the navigation container in logical pixels.
NavoraXConfig elevation double 4.0 Shadow elevation depth of the container.
NavoraXConfig blurAmount double 16.0 Backdrop filter blur intensity for glassmorphic styles.
NavoraXConfig activeColor Color? Color(0xFF6366F1) Active selected tab icon & label text color.
NavoraXConfig inactiveColor Color? Color(0xFF94A3B8) Unselected tab icon & label text color.
