# CHANGELOG

## 1.0.0

- Initial production release of **NavoraX: Bottom Navigation Design System for Flutter**.
- Core **Navigation Engine** with custom painters for glassmorphic, neumorphic, notched, curved, liquid, and floating dock shapes.
- **1000+ Template Registry** with category filters and search support.
- **SmartNavBuilder** fluent Navigation Composer for custom design combinations.
- **Adaptive Engine** for light/dark, OLED dark, tablet screen sizes, and reduced motion settings.
- **Context-Aware Navigation** & **SmartNavigation** runtime controller.
- **Badge System** with count, dot, text, and animated pulse support.
- **Center FAB Action** with notched clipping support.
- **Performance Engine** for graphics scaling.
- Abstract **AI Generation (`SmartNavAI`)** and **Remote Configuration (`JsonNavigationConfigProvider`)** interfaces.
- Interactive **Example Gallery App** with code generator.
- Comprehensive unit and widget tests.
